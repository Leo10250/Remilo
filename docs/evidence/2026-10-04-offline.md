## Dependency and compatibility observations

A fresh npm audit reports **29 affected dependency entries: 20 high, nine moderate,
zero critical**. Several entries propagate from tooling/configuration dependencies;
this count is not a finding that every named package has a distinct runtime flaw.
Runtime reachability has not been fully assessed, so this is not a security-clean
release claim. The reported automatic fixes include incompatible Expo downgrades;
none were applied to the agreed SDK 57 / React Native 0.86 baseline.

The root advisories include braces nested-pattern stack exhaustion, node-forge
signature validation, and uuid buffer-bound handling. Upstream upgrade/advisory
assessment remains necessary before broader distribution. The earlier URI-decoder
patch remains in place and its regression tests pass. Gradle reports future Gradle
10 deprecations; the pinned Gradle 9.3.1 build passes. The scoped third-party lint
fallback is documented in the architecture decisions.

Calendar, cloud/accounts and iOS are deferred behind their existing optional gates.
They are absent from this offline build and its acceptance claims.
