# P02-sample-r1 — attributed expansion checkpoint

[A17](../design/p02/artwork-r1-acceptance.json) accepts Sky SK1 and Rose RO1.
The [actual sample](../design/p02/sample-review-r1.html) submits their treatments,
colors and controls for the next owner checkpoint. The source selection is accepted;
the rendered sample and complete catalog are separate decisions.

## Implemented and exercised

- Canonical schema-1 sample catalog; static TS/Kotlin values, matching PNG bytes,
  explicit RN aliases/36 Compose mappings and normalized placement descriptors.
- Dedicated deterministic export/check/help interface; pinned MCU 0.4.0 authoring
  and bundled Sharp 0.35.4. Eight exports total 7,415,492 unique image bytes.
- Opt-in shared foundation controls, 16 dp tile option, explicit readable states,
  reserved icon/progress space and growing multiline fields. Current production
  providers/layouts remain on their existing styling. Native optional presentation
  has no new action or dismissal lifecycle.
- Actual RN rows, buttons, inputs, choice/toggle, feedback and sheets; actual
  AlarmControlsScreen and Compose Material controls. Source top/bottom anchors are
  applied explicitly. Artwork is decorative and reserves no content space.
- Static unknown-ID, invalid-color-token, missing-art and emergency fallbacks,
  with no preference/content/scheduling mutations; generic native Classic canvas.

## Captures and measurements

The RN index contains 472 unmodified captures (236 pairs); native contains 288
unmodified captures (144 pairs). Both renderer indices retain fixture inputs,
viewport, scale, bounds, renderer and image hashes. Paired backgrounds retain the
same text nodes, wrapping and geometry. Top/end controls are captured; primitive
RN galleries also capture the middle. Four actual shared-sheet captures and an
enabled/disabled/busy interaction observation supplement the matrix.

At 360×800, Sky/Rose cover light/dark, 100/200%, standard, long English and authored
Simplified Chinese, with browsing/individual RN and actual native single controls.
Sunrise/Meadow provide standard 100/200% anchors. 412×915 and 800×1024 cover both
new environments/brightnesses with standard100% and Chinese200%. Targeted native
loading, multiple, generic, error and busy states, RN/native fallbacks and RN
reduced motion supplement this sample. Complete eight-environment coverage remains
the catalog-stage requirement, not a claim of this checkpoint.

Browser host evidence uses RN 0.86.3/react-native-web and the opt-in resolver;
native uses Robolectric 4.17 native graphics, API 35, mdpi and synthetic zero
insets. Browser physical viewport requests are calibrated against measured CSS
dimensions. Raw screenshot bitmaps receive the host's additional density
normalization and padding, as in P01. Inverse measured density maps CSS bounds to
pixels. Labeled view crops remove only that padding; originals remain unchanged.
Glyph extents exclude invisible trailing whitespace; essential text is checked
against its own box and samples respect ancestor clips. Native uses P01's measured
one-raster-pixel tolerance for fractional Skia line extents.

[Composite verification](redesign-p02/sample-r1/render-verification.json) passes:
380 pairs, 5,444 sampled text/essential-icon elements, minimum 5.1477:1, no failures.
Normal text uses 4.5:1; qualifying large text/icons use 3:1. Native essential
control boundary checks pass against their actual adjacent opaque surface.
RN targets measure at least 48 dp; focused native assertions preserve 48 dp touch
bounds and 64 dp single-alarm actions. No clipped essential glyphs or unreachable
bottom actions were found in this matrix. Decorations are excluded from semantics
and hit testing; text, icons and checked shapes retain non-color state cues.
The grayscale overview is a labeled post-render derivative, not device evidence.

## Resolved observations and limits

Initial native loading/multiple headings and an RN grouped heading could touch
Rose/Meadow foliage. They received opaque reading surfaces; the final composite
checks above use the corrected renders. Multiline Chinese fields now grow to fit.
Capture trials exposed transient scroll rounding and host viewport normalization;
fixed paired offsets, paint-settled measurement and calibrated full canvases
resolved them. Initial metadata-helper compilation and missing Buffer import were
corrected without weakening existing assertions or changing stack versions.

P01 artwork/submitted renders/manifests/approval records are preserved. Shared
source intentionally evolves under P02; historical P01 file fingerprints are not
misrepresented as hashes of the current shared source. Storage versions stay 4/3/3.

No build was installed or distributed. TalkBack, Android keyboard/Back, real insets,
physical performance and alarm reliability remain P12/device observations. Sample
acceptance precedes generation of Classic/Peach/Lavender/Mist sources; subsequent
source and complete-catalog gates precede production Classic activation. P02 is
not complete at this checkpoint; live status is only in the backlog.
