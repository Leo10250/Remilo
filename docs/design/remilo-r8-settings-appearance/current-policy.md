# Current Appearance policy correction

8 October 2026 · [A36](../approved-time-of-day-realignment.json).

The unchanged R8-03/R8-04 screenshots show the former four-scene tile selector and
held Automatic behavior. Implementation now uses a single Atmosphere dropdown:
Automatic / Sunrise / Sky / Evening / Night, separate from System / Light / Dark
brightness. Missing/new atmosphere preferences default to Automatic while
brightness is preserved.

Automatic local intervals are Sunrise 06–10, Sky 10–17, Evening 17–21 and Night
21–06. Manual selection persists until Automatic is selected. See the complete
[appearance policy](../current/appearance-policy.md) for lifecycle/session handling.

Keep the [original gallery](gallery.html), screenshot hashes and submitted r1
specification unchanged. This note supersedes selector/availability differences;
it does not alter image approval history or claim implemented preferences.
