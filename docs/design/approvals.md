## Current decision boundaries

- A01 fixes the faithful static Classic identity; standard Android adaptive and
  monochrome exports do not authorize dynamic variants. The preserved [crop](../../assets/brand/reference/icon-classic.png)
  and [source board](../../assets/brand/reference/source-icon-board.png) supply fidelity.
- A18–A35 accept the reference directions within their recorded scope and retain
  per-image corrections. R3 governs color/style; current page contracts govern UX.
  Frozen submissions and rejected images inside accepted bundles are provenance.
- A36 supplies Automatic/four manual atmospheres, approved local periods/defaults,
  independent brightness and static identity. R9 remains draft and list icons
  remain provisional. Accepted templates do not establish runtime accessibility.
- A37 authorizes the cleanup, including non-shipping demos and their dedicated
  tests, while preserving implemented behavior and ordinary web preview isolation.
  It introduces no production appearance API, schema or scheduling changes.

Add consequential decisions only after a direct owner instruction, recording the
accepted scope, conditions and affected artifact identities. Current TD handoffs
record actual implementation and verification separately from template approval.
