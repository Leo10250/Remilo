# Classic identity source

[The supplied Classic board](supplied-classic-icon-board.png) preserves the exact
large ring/check/sun identity accepted under A01. Its SHA-256 is
`b7d19ae659fc43b747f468fbef91f674f19b235b739b8cf87ed83aefdb2fb849`.
Only the large Classic mark governs current branding; smaller color variants on
the board are source context, not a current icon catalog.

The preserved [Classic crop](../../../assets/brand/reference/icon-classic.png) and
[original source board](../../../assets/brand/reference/source-icon-board.png)
retain their original pixels. [Their provenance manifest](../../../assets/brand/reference/manifest.json)
records source hashes and crop rectangle: left 491, top 68, width 467, height 467.
The crop is source artwork, not an accepted production adaptive layer or export.
Preserve geometry and finish; adapt isolation, layers, padding and sizing only.

[TD-05](../../plans/redesign/td-05-static-branding.md) owns production exports and
actual small-size/mask/device validation. Shipped geometric R assets remain in
place until that implementation. One static Classic identity is planned.

For app artwork, colors and scene treatment, use all eight [R3 references](../remilo-r3-atmospheres/gallery.html)
and [the current design](../current/README.md). Superseded botanical/theme
inspiration and rejected prototype references were removed under A37.
