# Approved UI direction: current entry points

The maintained [current design](current/README.md) consolidates R3–R10 references,
[shared visual/keyboard corrections](current/visual-language.md),
[Details/Editor per-image corrections](current/screens/details-editor.md) and
[global appearance policy](current/appearance-policy.md). All eight R3 images govern
color/art/style; approved page UX and recorded corrections govern workflow.

[A18/A19](approved-ui-r3-r4-acceptance.json) and subsequent acceptance records retain
their historical scope. [A36](approved-time-of-day-realignment.json) establishes
this consolidation, automatic/manual policy and static Classic identity.

Superseded living specifications were removed under A37. Accepted reference
bundles and their correction records remain intact; this path routes to the
maintained contracts rather than duplicating requirements.
[Backlog](../backlog.md) alone records task status.
