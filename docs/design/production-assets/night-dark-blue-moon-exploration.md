# Night Dark blue-moon exploration

The owner approved the Classic legacy launcher exports, then separately requested
an example of a blue crescent for Night Dark. This authorizes an exploration;
replacing the active scene requires a separate explicit artwork/crop decision.

The subsequent [shoreline-light request](night-shoreline-lights-revision.md) adds
that scenic detail to both Night variants and extends this Dark candidate before
an adoption decision. The original blue-moon prompt and reference evidence remain
as the record of the earlier single-color exploration.

Night Dark v1 and its approval remain intact. Candidate 02 uses ignored local
review files and has no production derivative or native resource copy. If adopted,
save a new `night-dark-v2` master, runtime derivative and matching native copy;
retain v1 files and approval, and update the active registry only after the owner's
explicit decision. Night Light is unaffected by this exploration request.

The shared 2048 × 1152 master target, no-upscale rule and 1440 × 810 runtime
contract still apply. Artwork approval does not amend dimensional requirements or
establish runtime contrast, wider/expanded-toolbar crops or device acceptance.
