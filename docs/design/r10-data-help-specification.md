The maintained specification is [data-help](current/screens/data-help.md).
Use [the current design](current/README.md), [appearance policy](current/appearance-policy.md)
and the existing native/product behavior. This former living path is a compatibility
entry point, not a second specification.

and gallery correction notes remain at their recorded paths. Frozen submissions
inside those bundles are provenance; the maintained contract governs implementation.
