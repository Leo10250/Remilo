# Static Classic reference

The [source icon board](source-icon-board.png) and [Classic crop](icon-classic.png)
retain the exact pixels accepted for the ring/check/sun identity under A01.
[The manifest](manifest.json) records original hashes and crop coordinates.
The [associated supplied board](../../../docs/design/references/supplied-classic-icon-board.png)
is preserved for the current documentation.

TD-05 will adapt this mark for launcher, adaptive, monochrome, splash and
notification exports. These are source references, not accepted final exports.
The shipped geometric R assets remain the implemented baseline until that unit
is separately executed. Current app identity is static; the smaller variants on
the original source board are not current app appearance options.

Read [the current design](../../../docs/design/current/README.md) and
[static branding plan](../../../docs/plans/redesign/td-05-static-branding.md).
